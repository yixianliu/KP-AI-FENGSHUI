## 一、这个软件是做什么的

**风水排盘专业工具** 是一款运行在你自己电脑上的传统术数排盘软件，集成了三大核心板块：

- **八字排盘** —— 依据出生时间排出四柱八字、十神、五行旺衰、格局与大运流年；
- **梅花易数** —— 用时间、数字、方位、文字、笔画、铜钱六种方式起卦，推演本卦、互卦、变卦与体用生克；
- **大六壬** —— 以太阳黄经定月将，排四课三传、十二天将与神煞，进行传统高级占法推演。

软件还提供可选的 **AI 智能解读（"龙虎山大师兄"）**：以本地排盘结果为唯一依据，输出结构化分析报告，把晦涩术语翻译成通俗易懂的人生参考。

## 三、它带来哪些独特价值

- **真正本地、真正隐私**：数据不出本机，离线也能用，彻底的"数据不上云"，适合对隐私有要求的严肃用户。
- **算法透明、结果可信**：区别于"黑盒"工具，排盘每一步都来自同一份本地数据与计算逻辑，展示与计算严格一致，杜绝"算一套、画一套"。

- **工程级质量保障**：内置 100+ 项单元测试，锁定万年历锚点与关键算法逻辑，持续保证排盘准确性。

## 五、主要功能一览

### 八字排盘
- 公历 / 农历自动互转
- 真太阳时经度修正（精确到分钟）
- 四柱（年 / 月 / 日 / 时）+ 藏干 + 纳音 + 空亡 + 十神
- 五行能量量化（月令权重 + 藏干本气 / 中气 / 余气）
- 格局判定（专旺 / 从格 / 扶抑 / 中和）+ 特殊格局
- 大运排列 + 流年分析 + 十二长生

### 梅花易数
- 六种起卦：时间 / 数字 / 方位 / 文字 / 笔画 / 铜钱
- 本卦 + 互卦 + 变卦 + 错卦 + 综卦
- 体用生克判断、动爻分析

### 大六壬
- 太阳黄经天文算法定月将（非经验表）
- 天地盘 + 四课（干上神 / 干阴 / 支上神 / 支阴）
- 九宗门三传 + 十二天将 + 神煞系统（驿马 / 空亡 / 六合等）

### AI 智能解读（可选）
- 可选接入"龙虎山大师兄"接口
- 以本地排盘数据为唯一输入，输出结构化分析报告
- 支持八字 / 梅花 / 六壬三类解读分支
- 本地结果缓存，避免重复请求

### 数据导出
- PDF / Excel / CSV，便于教学存档、咨询归档与分享

## 六、使用方式

**方式一：运行源码（需 Python 环境）**

```bash
pip install -r requirements.txt
python main.py
```

**方式二：使用已打包的 Windows 程序**

直接运行 `dist/` 目录下生成的"风水排盘专业工具"可执行文件，无需安装 Python。

> AI 解读为可选功能，需在设置中自行配置合法 API 密钥后方可使用；不配置也能完成全部排盘与导出功能。

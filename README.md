## 一、产品定位与愿景

### 1.1 一句话定义

**一套完全本地运行的中国传统术数排盘与分析工具，将八字、梅花易数、大六壬、玄空飞星四大体系集成于单一桌面应用，算法严谨可验证，AI 解读可选且受控。**

**用户核心获益**：KP-AI-FENGSHUI 为用户解决「排盘不准、算法黑盒、隐私泄露、多工具割裂、解读无据」五大痛点，带来「可验证的古法严谨性、100% 本地隐私主权、双轨可控 AI、四大体系一体化、专业导出与工程质量」五大独特价值，让传统命理研究与应用回归确定、可控、可信。

### 1.2 愿景

让中国传统命理学的研究和学习回归严谨、透明与可控，消除在线工具的隐私风险与算法黑盒问题，成为传统文化数字化传承的工程级参考实现。

### 1.3 核心设计哲学

| 原则 | 含义 |
|------|------|
| **确定性优先** | 排盘计算 100% 本地执行，任何结果均可复现、可验证 |
| **隐私主权** | 敏感数据永不离开本机，AI 解读仅为可选增值功能 |
| **算法透明** | 每一步计算均有古籍出处标注，杜绝"算一套、画一套" |
| **渐进式交付** | 无网络时仍可完成排盘，有网络时可启用 AI 增强解读 |

### 2.2 核心痛点清单

#### 痛点一：在线工具排盘结果不准确

**问题描述：**  
市面主流在线八字排盘工具普遍存在以下算法偏差，导致同一输入在不同平台得出不同结果：

| 偏差类型 | 典型错误表现 | 后果 |
|----------|------------|------|
| **年柱分界错误** | 以公历 1 月 1 日为年柱分界，而非立春 | 立春前后出生者年柱全盘错误 |
| **时辰计算偏差** | 使用北京时间（东八区）而非真太阳时 | 边疆地区（如新疆）偏差可达 1-2 小时 |
| **晚子时处理错误** | 23:00-24:00 归入次日而非当日 | 夜子时命局全盘错误 |
| **节气取月不准确** | 简单按月整数划界，未按节气时刻精确分月 | 节气日出生的月柱错误 |

**具体案例：**  
以 1990 年 2 月 4 日（立春当天）上午 10 点出生、地点在北京为例：
- 正确做法：以精确立春时刻（2 月 4 日约 6:07）为界，该时刻后属己巳年
- 错误做法：若以公历元旦为界，仍属戊辰年，年柱错误

**本项目解决方案：**  
- 采用儒略日二分查找算法精确计算 24 节气时刻（精度达秒级）
- 年柱严格以立春时刻为界，不依赖月份整数
- 真太阳时按城市经度自动修正，`均时差 + 经度修正 = 真太阳时`
- 晚子时（23:00-23:59）明确归属当日，早子时（00:00-00:59）归属次日

#### 痛点二：算法黑盒，无法验证结果可信度

**问题描述：**  
多数商业命理工具以"结果已给出"为卖点，但不暴露计算过程，用户无法判断：
- 这个四柱对不对？
- 大运起运岁数怎么算的？
- 神煞是随机生成的还是有依据的？

用户被迫"信任工具"，一旦发现误差也无法定位根因。

**本项目解决方案：**
- 所有算法逻辑开源可查，每步计算有注释标注古籍出处
- 内置 100+ 项单元测试，覆盖已知历史锚点（如 1949-10-01=甲子）
- 结果面板逐项展示计算中间值（藏干、纳音、神煞来源），便于人工复核

#### 痛点三：隐私泄露风险——出生信息被上传至云端

**问题描述：**  
主流在线排盘工具通常需要用户注册账号，并将以下信息上传至第三方服务器：
- 出生年月日时（精确到分钟）
- 出生地点（城市/经纬度）
- 姓名、性别
- 部分工具甚至采集设备指纹，用于用户画像

这些信息属于个人敏感数据，一旦泄露或被滥用，后果严重。

**本项目解决方案：**
- 排盘全程本地运行，不依赖网络，不上传任何个人信息
- AI 解读为**可选功能**，仅在用户主动触发时发送脱敏摘要（不含姓名）
- API Key 采用 `enc:v1:` 混淆存储于本地，源码中无明文密钥
- 打包产物经自动化安全扫描，杜绝密钥泄漏

#### 痛点四：解读内容质量参差不齐，缺乏古籍依据

**问题描述：**  
当前 AI 命理解读工具普遍存在以下问题：
- "巴纳姆效应"式泛化描述，放之四海而皆准但毫无针对性
- 编造不存在的古籍出处，误导用户
- 学理定论与模型生成内容混杂，用户无法区分
- 缺乏对排盘具体参数的引用，解读流于空泛

**本项目解决方案：**
- RAG 知识库基于五部权威古籍（《子平真诠》《滴天髓》《穷通宝鉴》《三命通会》《渊海子平》），按章节切分为 500-800 字符块
- BM25 + 向量混合检索，top-K=5 按相关度重排序，确保古籍原文优先
- AI 解读强制三段式结构（格局总评 → 分项分析 → 建议与注意事项），每条论断必须引用具体参数
- 输出末尾自动追加免责声明，明确标注"仅供文化研究参考"
- 区分「学理定论」与「民俗说法」双层标注

#### 痛点五：多体系分散在多个工具，切换成本高

**问题描述：**  
传统命理学包含八字、梅花易数、大六壬、玄空飞星等多个独立体系，市面工具普遍只做其中一种或两种。用户需要：
- 八字 → 工具 A
- 梅花易数 → 工具 B
- 玄空飞星 → 工具 C
- 每个工具界面风格、操作流程、数据存储各不相同

**本项目解决方案：**
- 四大体系集成于同一窗口，标签页切换无缝衔接
- 统一的数据输入格式、导出流程、设置体系
- 跨体系的共同数据结构（排盘记录、历史搜索）一次实现

#### 痛点六：结果难以保存和分享

**问题描述：**  
网页排盘结果转瞬即逝，无法保存；截图画质差、排版乱；打印格式不规范。专业从业者需要将这些结果作为咨询材料交付客户，但缺乏标准化工具。

**本项目解决方案：**
- 一键导出 PDF（含排版精美的四柱九宫图）、Excel（结构化数据）、CSV（轻量格式）
- 历史记录持久化至本地 SQLite，随时回溯
- 支持完整导出 AI 解读内容，便于整理成正式报告

## 三、典型使用场景

### 场景一：命理研究者的算法验证

> 用户背景：某大学宗教学研究所研究生，撰写论文《清代子平八字算法的现代复现》

**需求：** 验证手写算法的正确性，需要与权威古籍和已有工具交叉比对。

**使用流程：**
1. 输入历史著名人物出生时间（如某皇帝生于某年某月某日某时）
2. 本地排盘得出四柱、大运、格局
3. 调出 AI 解读，验证其是否引用《子平真诠》《滴天髓》等原文
4. 导出 Excel，与文献记载逐一比对
5. 发现差异时，查阅核心代码定位根因（如某节气时刻计算偏差）

**关键价值：**
- 所有计算过程可追溯至代码，便于学术论证
- 测试结果库提供已知历史锚点（如 1949-10-01=甲子），可直接引用

### 场景二：风水从业者的现场咨询

> 用户背景：独立风水咨询师，上门为客户提供住宅风水布局建议

**需求：** 快速生成九宫飞星盘，打印后作为咨询材料交付客户。

**使用流程：**
1. 在客户住宅内，使用电脑输入坐向（如"子山午向"）和建造年份
2. 点击"排盘"，即时显示九宫格飞星图（Canvas 绘制，颜色区分吉凶）
3. 查看 AI 解读，获取专业术语解释和布局建议
4. 导出 PDF，打印后附在咨询报告末尾
5. 历史记录自动保存，下次客户来访可直接调取

**关键价值：**
- 离线可用，无需现场网络
- 九宫图专业渲染（五行色标、生克箭头），交付品质高
- 导出 PDF 格式规范，可直接装入咨询报告

### 场景三：命理爱好者的自学对照

> 用户背景：自学八字三年，希望能有一个工具来验证自己的手算结果

**需求：** 输入自己的出生信息，得到排盘结果，逐行核对是否与手算一致。

**使用流程：**
1. 打开软件，选择"八字排盘"
2. 输入个人信息（姓名、性别、出生日期时间、城市）
3. 点击排盘，查看四柱、藏干、纳音、十神、神煞
4. 与自己的手算结果对比
5. 如发现差异，点击对应字段查看详细算法说明（代码注释中有古籍出处）
6. 可选：开启 AI 解读，获得更通俗的命理分析

**关键价值：**
- 算法透明，便于学习理解
- 神煞、纳音等知识点均有数据来源可查
- 无需注册、无需联网，随时可用

### 场景四：数据安全保障要求高的用户

> 用户背景：某企业高管，对个人信息高度敏感，拒绝使用任何需要注册的在线命理工具

**需求：** 需要一个不上传任何数据的排盘工具。

**使用流程：**
1. 下载并解压便携版（dist 目录中的 EXE + `_internal/`）
2. 直接运行，无需安装，无需注册账号
3. 输入出生信息后本地即时出盘
4. 全部数据存储于本地 SQLite（`data/fengshui.db`），永不联网
5. 如需 AI 解读，在设置中填入本地密钥（仅存本机）

**关键价值：**
- 真正零网络依赖，真正数据不出本机
- 便携版即开即用，不写注册表、不留痕迹
- 代码开源，可自行审查安全性

### 场景五：传统文化教学培训

> 用户背景：培训机构讲师，教授传统命理学课程

**需求：** 需要一套教学工具，能演示算法全过程，便于学生理解。

**使用流程：**
1. 课堂上展示软件界面，实时输入示例案例
2. 学生观察排盘各字段的计算过程
3. 导出 CSV，布置学生手算作业并批改
4. 利用 AI 解读功能，展示古籍原文如何支撑具体论断
5. 将源码作为参考资料，引导学生理解算法实现

**关键价值：**
- 代码可读性强，适合作为教学范本
- 数据库种子数据即教学内容（如六十甲子、纳音表、神煞术语）
- 测试用例可作为课后练习题

### 4.2 六大独特价值

#### 价值一：古法严谨，可验证

排盘算法严格遵循《子平真诠》《滴天髓》《穷通宝鉴》《三命通会》《渊海子平》等五经论断，关键节点均有古籍出处标注：

| 算法环节 | 古籍依据 |
|----------|---------|
| 年柱以立春为界 | 《子平真诠·卷一》 |
| 月柱五虎遁 | 《滴天髓·通神论》 |
| 日柱儒略日算法（锚点 1949-10-01=甲子） | 《三命通会·日时历例》 |
| 时柱五鼠遁 | 《子平真诠·卷九》 |
| 真太阳时修正 | 《渊海子平·卷三》 |
| 晚子时归属当日 | 传统通例 |

用户可对照古籍原文进行交叉验证，这是绝大多数商业工具无法做到的。

#### 价值二：100% 本地，隐私零暴露

所有计算在本地完成，包括：
- 四柱干支推算
- 大运流年排盘
- 神煞纳音计算
- 玄空飞星九宫排布
- 梅花易数起卦推演
- 大六壬九宗门起课

**AI 解读为完全可选功能**：
- 用户可选择不启用 AI，享受完整的离线排盘体验
- 启用时，仅发送脱敏后的排盘摘要，不含姓名等身份信息
- API Key 混淆存储于本地，不落云端

│  确定层（Core）                                │

                   │
                   ▼
┌──────────────────────────────────────────────┐
│  解读层（AI + RAG）                           │

这是工程架构层面的核心创新：确保排盘数据的确定性和 AI 解读的辅助性，两者边界清晰，互不干扰。

统一的操作界面、导入导出流程、设置体系，降低学习成本。

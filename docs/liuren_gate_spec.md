## 一、九宗门总则

大六壬以日干支加时定课，四课三传为体。九宗门是确定初传（发用）的九种法则，按日干阴阳、天地盘关系分类。

**判定流程**：
1. 排天地盘（月将加时）
2. 定四课（日干两课、日支两课）
3. 取三传（贼克、比用、涉害、遥克、昴星、伏吟、返吟、别责、八专）

---

## 二、九宗门详细规则

### 1. 贼克（元首、重审）

**条件**：四课中有上克下或下贼上。

#### 1.1 元首课（一克）
- 仅有一处上克下（干上神克干）
- 取克者为初传
- 特点：尊卑有序，以尊临卑

**古籍依据**：《毕法赋》"元首为课端可取"

#### 1.2 重审课（一下贼上）
- 仅有一处下贼上（支上神克支）
- 取贼者为初传
- 特点：卑逆尊，事多反复

**古籍依据**：《毕法赋》"重审为课卑侮尊"

#### 1.3 兼有贼克
- 同时存在上克下和下贼上
- 取重者（多者为先），同数取日上

### 2. 比用（知一）

**条件**：有多处下贼上或上克下，数量相同。

**取法**：
- 多选一（通常取日上者）
- 若无日上者，取日阴

**古籍依据**：《六壬指南》"比用多贼，知一为先"

### 3. 涉害（艰穿）

**条件**：比用无法取舍时，比较涉害深浅。

**取法**：
1. 各取所乘之神，看其落入何宫
2. 计算归本宫所经历的克害次数
3. 涉害深者（经历多）为初传
4. 涉害浅者（经历少）为初传
5. 同深浅则取日上

**古籍依据**：《毕法赋》"涉害深时归本宫"

### 4. 遥克（蒿矢、弹指）

**条件**：四课中无克无贼，日干与地支遥克。

#### 4.1 蒿矢课（日干克日支上神）
- 日干克四课中某上神
- 特点：远而无力，事多虚浮

#### 4.2 弹指课（日支上神克日干）
- 四课中某上神克日干
- 特点：猝然而至，事出意外

**古籍依据**：《六壬大全》"遥克为课，蒿矢弹指"

### 5. 昴星（伏阴）

**条件**：四课无克无贼，亦无遥克。

**取法**：
- 阳日（甲丙戊庚壬）：取酉上神为初传，顺行
- 阴日（乙丁己辛癸）：取亥上神为初传，逆行

**古籍依据**：《毕法赋》"昴星幽隐事难明"

### 6. 伏吟（郁仪）

**条件**：天地盘完全重合（月将加时令伏）。

**取法**：
- 有克者取克
- 无克者：
  - 阳日：取日干上神为初传，顺行
  - 阴日：取日支上神为初传，逆行
- 三传皆用本宫

**古籍依据**：《六壬指南》"伏吟之课，气郁难伸"

### 7. 返吟（安车）

**条件**：天地盘对冲（月将加时正冲）。

**取法**：
- 有克者取克
- 无克者：
  - 阳日：取日干上神为初传
  - 阴日：取日支上神为初传
- 三传皆用对冲之神

**古籍依据**：《毕法赋》"返吟有克兼无克"

### 8. 别责（杂占）

**条件**：四课不备（只有两课）。

**取法**：
- 阳日：取日干合神为初传
- 阴日：取日干寄宫为初传
- 三传顺行

**古籍依据**：《六壬大全》"别责者，不备而别取也"

### 9. 八专（幽微）

**条件**：天地盘伏，四课不备。

**取法**：
- 阳日：取日干上神为初传
- 阴日：取日支上神为初传
- 三传顺行

**古籍依据**：《毕法赋》"八专幽微事不清"

## 三、九宗门优先级

```
贼克 → 比用 → 涉害 → 遥克 → 昴星 → 伏吟 → 返吟 → 别责 → 八专
```

每级有定法，不可跳级。

---

## 四、三传推导规则

确定初传后，中传、末传推导规则：

1. **初传** → 中传：取初传所乘之神上之神
2. **中传** → 末传：取中传所乘之神上之神
3. **特殊情况**：
   - 涉害课：涉害深者传中，次者传末
   - 伏吟返吟：按特定规则逆行或顺行

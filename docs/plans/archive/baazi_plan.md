# 八字排盘应用程序开发计划

## 一、需求分析

### 1.1 功能需求
根据用户需求，八字排盘应用程序需要实现以下功能：

| 需求点 | 描述 | 优先级 |
| :--- | :--- | :--- |
| 用户信息输入 | 姓名输入框、性别选择（男/女） | 高 |
| 出生日期选择 | 支持公历/农历切换的日期选择器 | 高 |
| 出生时间选择 | 时辰选择（24小时制或十二时辰） | 高 |
| 八字排盘计算 | 根据输入信息计算四柱八字 | 高 |
| 十神分析 | 分析并展示十神关系 | 高 |
| 五行分布 | 展示五行元素的分布情况 | 高 |
| 命局格局 | 分析并展示命局格局 | 高 |

### 1.2 界面设计要求
- 输入区域与结果显示区域布局清晰、层次分明
- 符合传统文化审美，采用中国风配色方案
- 保持现代UI设计标准，直观易用

## 二、技术方案

### 2.1 技术选型

| 分类 | 技术 | 版本 | 理由 |
| :--- | :--- | :--- | :--- |
| 语言 | Python | 3.8+ | 成熟稳定，生态丰富 |
| GUI框架 | PyQt5 | 5.15+ | 功能强大，跨平台支持好 |
| 八字计算 | 自建算法 | - | 无需外部依赖，自主实现八字排盘逻辑 |
| 公历农历转换 | lunarcalendar | 0.0.9+ | 成熟的农历转换库 |

### 2.2 项目结构

```
KP-AI-FENGSHUI/
├── main.py                    # 主程序入口
├── ui/
│   ├── main_window.py         # 主窗口UI
│   └── components/            # UI组件
│       ├── input_panel.py     # 输入面板
│       └── result_panel.py    # 结果面板
├── core/
│   ├── baazi.py               # 八字排盘核心算法
│   ├── wuxing.py              # 五行分析模块
│   └── shishen.py             # 十神分析模块
└── utils/
    └── calendar.py            # 公历农历转换工具
```

### 2.3 核心功能模块

#### 2.3.1 八字排盘核心算法 (`core/baazi.py`)
- 根据出生年月日时计算四柱
- 支持公历/农历输入
- 确定日主天干
- 计算十二长生状态

#### 2.3.2 五行分析模块 (`core/wuxing.py`)
- 分析八字中的五行分布
- 计算五行强弱
- 生成五行平衡建议

#### 2.3.3 十神分析模块 (`core/shishen.py`)
- 根据日主确定十神关系
- 分析十神在四柱中的位置
- 判断十神强弱

#### 2.3.4 输入面板 (`ui/components/input_panel.py`)
- 姓名输入框
- 性别选择（单选按钮）
- 公历/农历切换按钮
- 日期选择器
- 时辰选择下拉框
- 提交按钮

#### 2.3.5 结果面板 (`ui/components/result_panel.py`)
- 四柱信息展示区
- 十神分析展示区
- 五行分布展示区（饼图或条形图）
- 命局格局分析区

#### 步骤4：八字排盘核心算法
- 定义天干地支常量

- 实现时柱计算

#### 步骤5：五行分析模块
- 定义五行与天干地支的对应关系

#### 步骤6：十神分析模块

## 五、依赖与风险

### 5.1 依赖列表
| 依赖 | 版本 | 用途 |
| :--- | :--- | :--- |
| PyQt5 | 5.15+ | GUI框架 |
| lunarcalendar | 0.0.9+ | 农历转换 |

### 5.2 风险与应对

| 风险 | 描述 | 应对措施 |
| :--- | :--- | :--- |
| 农历转换精度 | 农历与公历转换可能存在误差 | 使用成熟的lunarcalendar库 |
| 节气计算 | 月柱需根据节气确定，而非月份 | 确保使用准确的节气数据 |
| 时辰划分 | 不同地区时辰划分可能不同 | 使用标准UTC+8时区 |
| 界面适配 | 不同分辨率屏幕适配 | 使用Qt布局管理器 |

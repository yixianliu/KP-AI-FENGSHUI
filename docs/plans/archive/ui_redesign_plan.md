# 八字排盘信息录入界面 UI 重设计方案

## 一、需求分析

根据用户要求，需要将现有的风水八字排盘程序首页UI界面重新设计，遵循以下核心原则：

### 1.1 设计风格要求
- **视觉风格**：现代极简设计与素雅国风元素融合
- **整体调性**：干净高级、充足留白、简约大气、清晰视觉层次
- **布局适配**：桌面端窗体布局，居中规整

### 1.2 色彩系统规范
| 元素 | 颜色值 | 用途 |
|------|--------|------|
| 纯白 | #FFFFFF | 基础底色 |
| 浅灰 | #F5F5F5 | 背景色 |
| 深黑灰色 | #333333 | 文字颜色 |
| 暗青墨色 | #2C3E50 | 强调色、主按钮 |
| 边框色 | #E0E0E0 | 控件边框 |

### 1.3 控件设计标准
- 圆角：8px
- 边框：纤细浅灰色(#E0E0E0)
- Hover状态：边框变为暗青墨色
- 字体：Microsoft YaHei / SimHei

### 1.4 功能布局要求
1. 页面顶部：简约国风标题「八字排盘 AI命理解析」
2. 卡片内垂直流式布局：
   - 性别选择（男/女）
   - 姓名输入框
   - 历法切换（公历/农历）
   - 出生日期（年/月/日下拉选择器，水平排列）
   - 出生时辰（十二时辰下拉选择器）
3. 底部按钮：
   - 主按钮「AI排盘解析」（暗青墨色填充）
   - 次要按钮「重置清空」（边框样式）

## 二、现有代码分析

### 2.1 项目结构
```
KP-AI-FENGSHUI/
├── ui/
│   ├── styles.py          # 样式定义
│   ├── main_window.py     # 主窗口
│   └── components/
│       ├── home_page.py   # 首页组件
│       └── input_panel.py # 输入面板
```

### 2.2 现有问题
1. 颜色系统不符合新规范（当前使用棕色系）
2. 控件样式不符合圆角和交互要求
3. 缺少姓名输入框和历法切换功能
4. 缺少重置清空按钮
5. 布局结构需要调整以符合居中卡片式设计

## 三、修改方案

### 3.1 修改 `ui/styles.py`
- 更新颜色系统为新规范
- 调整控件样式（圆角8px）
- 添加切换按钮样式（性别/历法切换）

### 3.2 修改 `ui/components/home_page.py`
- 重新设计首页布局为居中卡片式
- 添加姓名输入框
- 添加历法切换功能
- 添加重置清空按钮
- 更新整体样式为新设计规范

### 3.3 修改 `ui/components/input_panel.py`
- 保持与首页一致的样式风格
- 添加重置清空按钮

## 四、详细实施步骤

### 步骤1：更新颜色系统 (`ui/styles.py`)
1. 修改 Colors 类，使用新的颜色值
2. 更新各控件样式的颜色引用
3. 添加切换按钮样式定义

### 步骤2：重新设计首页 (`ui/components/home_page.py`)
1. 重构卡片布局结构
2. 添加姓名输入框组件
3. 添加历法切换组件（公历/农历）
4. 修改出生日期选择器为水平排列
5. 添加重置清空按钮
6. 更新验证逻辑

### 步骤3：同步更新输入面板 (`ui/components/input_panel.py`)
1. 保持与首页一致的视觉风格
2. 添加重置清空按钮功能
3. 确保数据传递格式兼容

### 步骤4：测试验证
1. 运行程序验证界面显示
2. 测试各控件交互功能
3. 验证输入验证功能

# AI功能修复计划

## 一、问题分析

### 1.1 异常表现
- API请求超时错误：`HTTPSConnectionPool(host='spark-api-open.xf-yun.com', port=443): Read timed out`
- 程序自动降级到本地分析，无法使用AI能力

### 1.2 问题定位

对比参考文件 `spark_api_reference.py`，发现以下差异：

| 对比项 | 当前实现 | 参考实现 | 问题分析 |
|--------|----------|----------|----------|
| **流式响应** | `stream=False` | `stream=True` | 流式响应更高效，减少超时风险 |
| **web_search工具** | 未配置 | `tools: [{type: web_search}]` | 可能影响API响应行为 |
| **用户标识** | `fs_shi` | `user_id` | 可能影响API认证 |
| **SSL验证** | `verify=False` | 未显式设置 | 网络环境问题 |
| **超时设置** | 60秒 | 未显式设置 | 仍存在超时风险 |

### 1.3 根本原因
1. 非流式响应模式下，API需要等待完整响应后才返回，增加超时概率
2. 缺少web_search工具配置，可能导致API行为不一致
3. 网络环境限制导致SSL连接不稳定

## 二、修复方案

### 2.1 修改 `core/ai_analyzer.py`

#### 修改内容：
1. **启用流式响应**：将 `stream=True`

4. **改进流式响应处理逻辑**

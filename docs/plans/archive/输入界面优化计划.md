# 输入界面优化计划

## 一、现状分析

当前输入面板存在以下问题：
1. 整体内边距较大（32px），布局不够紧凑
2. 标题和副标题占用较多空间
3. 表单字段间距较大（垂直间距24px）
4. 标签与输入区域的视觉层次不够清晰
5. 错误提示区域占用空间较大

## 二、优化目标

1. **紧凑布局**：减少不必要的留白和间距
2. **功能优先**：去除装饰元素，专注核心功能
3. **流畅体验**：优化字段排列顺序，减少滚动
4. **清晰反馈**：错误提示清晰可见

## 三、优化方案

### 3.1 布局结构优化

**调整前**：
- 标题 + 副标题 + 表单 + 错误提示 + 按钮
- 内边距：32px
- 字段垂直间距：24px

**调整后**：
- 精简标题区域，合并标题和提示
- 内边距：20px（上下），24px（左右）
- 字段垂直间距：16px

### 3.2 字段排列优化

**优化前顺序**：
1. 姓名
2. 性别 + 历法
3. 出生日期 + 出生时辰

**优化后顺序**（更符合填写习惯）：
1. 姓名
2. 性别
3. 出生日期
4. 出生时辰
5. 历法（次要选项，移至下方）

### 3.3 输入框尺寸优化

| 字段 | 原尺寸 | 优化后尺寸 | 说明 |
|------|--------|-----------|------|
| 姓名 | 默认宽度 | 200px | 姓名通常不超过10个字符 |
| 出生日期 | 默认宽度 | 160px | 日期格式固定 |
| 出生时辰 | 默认宽度 | 180px | 下拉选项固定 |

### 3.4 视觉层次优化

1. **标签样式**：加粗、右对齐，与输入框形成视觉对比
2. **输入框焦点状态**：清晰的焦点边框
3. **错误提示**：内联显示，紧邻相关字段

### 3.5 错误提示优化

- 移至对应字段下方
- 采用图标+文字组合
- 保持简洁明了

## 四、实施步骤

### 阶段一：重构布局结构
- 精简内边距和间距
- 调整字段排列顺序
- 合并标题区域

### 阶段二：优化输入控件
- 调整输入框尺寸
- 优化标签样式
- 增强焦点反馈

### 阶段三：优化错误提示
- 内联显示错误
- 使用清晰的视觉提示

### 阶段四：测试验证
- 测试表单填写流程
- 验证响应式布局

1. 表单更加紧凑，减少滚动需求
2. 视觉层次清晰，填写更直观
3. 错误提示及时可见
4. 整体风格简洁实用

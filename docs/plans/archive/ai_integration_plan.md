# AI分析功能集成计划

## 一、需求分析

### 1.1 用户需求概述
将AI分析功能通过API接口集成到现有八字排盘程序中，实现以下完整工作流程：
1. 获取用户输入的八字排盘相关信息
2. 基于用户输入内容生成完整的八字排盘数据
3. 将生成的八字排盘数据通过API请求发送给AI进行专业命理分析
4. 接收并解析AI返回的分析结果
5. 将格式化后的AI分析内容准确显示在程序界面右侧的内容面板中

### 1.2 参考文件分析
`http.py` 提供了完整的API调用实现：
- 使用讯飞星火API (`https://spark-api-open.xf-yun.com/v2/chat/completions`)
- 支持流式响应
- 使用Bearer Token认证
- 包含系统角色定义（风水大师）

## 二、实施计划

### 2.1 核心修改内容

#### 2.1.1 修改 `core/ai_analyzer.py`
- 将本地AI分析替换为API调用
- 保持与现有接口兼容（`analyze`方法签名不变）
- 添加错误处理和超时机制
- 支持流式响应处理

#### 2.1.2 数据格式转换
确保API返回数据格式与现有UI期望格式一致：
```python
{
    'overview': str,           # 概述
    'personality': list,       # 性格特质
    'life_trends': str,        # 人生趋势
    'opportunities': list,     # 机遇
    'challenges': list,        # 挑战
    'compatibility': str,      # 五行调和
    'recommendations': list    # 建议
}
```

### 2.2 安全与稳定性保障

#### 2.2.1 API认证管理
- 使用环境变量存储API密钥（可选）
- 添加请求频率限制
- 实现请求重试机制

#### 2.2.2 错误处理
- 网络超时处理（10秒超时）
- API错误码处理
- 优雅降级（API不可用时使用本地分析）

### 2.3 文件修改清单

| 文件路径 | 修改内容 | 优先级 |
|----------|----------|--------|
| `core/ai_analyzer.py` | 替换为API调用实现 | **高** |
| `http.py` | 保留作为参考，可删除或整合 | 低 |

## 三、API调用实现方案

### 3.1 请求数据结构
```python
{
    "model": "x1",
    "user": "fs_shi",
    "messages": [
        {
            "role": "system",
            "content": "你是一位专业的命理大师..."
        },
        {
            "role": "user",
            "content": "请分析以下八字：年柱XXX 月柱XXX 日柱XXX 时柱XXX..."
        }
    ],
    "stream": True
}
```

### 3.2 响应处理
- 解析流式响应中的 `reasoning_content` 和 `content`
- 将AI返回的自然语言分析转换为结构化数据
- 处理特殊字符和编码问题

## 五、风险评估

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| API密钥泄露 | 安全风险 | 使用环境变量或配置文件 |
| API服务不可用 | 功能降级 | 实现优雅降级至本地分析 |
| 网络超时 | 用户体验 | 设置合理超时时间和重试机制 |
| API响应格式变化 | 程序崩溃 | 添加数据格式校验和异常处理 |

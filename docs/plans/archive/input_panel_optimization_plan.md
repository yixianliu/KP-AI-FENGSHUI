# 输入面板优化计划

## 需求概述
在左侧输入面板中添加姓名输入字段，并修复高级设置区域的显示问题。

## 具体任务

### Task 1: 添加姓名输入字段
- **Priority**: P0
- **Description**:
  - 在表单顶部添加姓名输入区域（性别选择之后）
  - 添加清晰的"姓名"标签
  - 使用QLineEdit控件，支持文本输入
  - 添加输入验证：非空检查、长度限制（最多20字符）
  - 验证失败时显示红色提示文字
  - 姓名非空时才允许提交

### Task 2: 修复高级设置展开/折叠功能
- **Priority**: P0
- **Description**:
  - 检查当前折叠/展开逻辑
  - 确保点击切换按钮时内容区正确显示/隐藏
  - 确保所有设置选项（真太阳时校正、起运计算规则、闰月处理方式）完整显示
  - 验证布局在展开状态下不出现挤压或重叠
  - 确保动画或状态切换流畅

### Task 3: 更新数据获取方法
- **Priority**: P1
- **Description**:
  - 修改`get_data()`方法，从姓名输入框获取实际值而非空字符串
  - 修改`clear()`方法，清空姓名输入框
  - 修改`validate_input()`方法，添加姓名非空验证

### Task 4: 功能测试与UI兼容性测试
- **Priority**: P1
- **Description**:
  - 测试姓名输入：正常输入、清空、特殊字符
  - 测试高级设置：展开、折叠、选择不同选项
  - 测试验证提示：错误信息显示是否正确
  - 测试在不同窗口尺寸下布局是否正常
  - 测试最小窗口尺寸下内容是否被截断

## 控件顺序（更新后）
1. 标题
2. 性别选择（乾造/坤造）
3. **姓名输入**
4. 历法切换（公历/农历）
5. 出生日期
6. 出生时辰
7. 出生地点
8. 高级设置（可折叠）

## 验证检查点
- [ ] 姓名输入框正确显示在性别选择下方
- [ ] 姓名标签清晰可读
- [ ] 输入框可正常输入文字
- [ ] 空姓名时显示红色提示"✘ 请输入姓名"
- [ ] 姓名超长时显示提示
- [ ] 高级设置可正常展开
- [ ] 高级设置可正常折叠
- [ ] 高级设置内所有选项完整显示
- [ ] 不同窗口尺寸下布局正常

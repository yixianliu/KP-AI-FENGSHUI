# Checklist - 单界面集成应用重构

## 布局验证

- [ ] 主窗口采用垂直三段式布局（Header、Content、Footer）
- [ ] 输入区域位于窗口顶部或内容区上方
- [ ] 结果区域位于输入区域下方
- [ ] 窗口最小尺寸设置为 800x600

## 输入面板验证

- [ ] 姓名输入框水平排列
- [ ] 性别选择（男/女）水平排列
- [ ] 历法切换（公历/农历）水平排列
- [ ] 日期选择器水平排列
- [ ] 时辰选择下拉框水平排列
- [ ] "开始排盘"按钮可见且位置合理
- [ ] "快速排盘"按钮存在

## 结果面板验证

- [ ] 四柱八字卡片显示正常
- [ ] 五行分布卡片显示正常
- [ ] 十神分析卡片显示正常
- [ ] 命局格局卡片显示正常
- [ ] 四张卡片垂直堆叠显示

## 交互功能验证

- [ ] 点击"开始排盘"按钮能触发计算
- [ ] 计算完成后结果自动显示
- [ ] 每张卡片支持折叠/展开操作
- [ ] 每张卡片有复制按钮
- [ ] 复制功能正常工作

## 导出功能验证

- [ ] 菜单栏导出选项存在
- [ ] 工具栏导出按钮存在
- [ ] 导出对话框能正常打开
- [ ] CSV导出功能正常
- [ ] Excel导出功能正常
- [ ] PDF导出功能正常

## 响应式设计验证

- [ ] 窗口宽度 >= 1000px 时布局正常
- [ ] 窗口宽度 700-999px 时布局正常
- [ ] 窗口宽度 < 700px 时卡片单列显示

## 样式验证

- [ ] 配色方案符合规范（主色 #5D4037、点缀色 #D4AF37、背景色 #FFF8E7）
- [ ] 字体层级清晰可读
- [ ] 卡片样式统一（白色背景、圆角、边框）
- [ ] 悬停效果正常

# 玄中易AI命理助手专业版 - 八字排盘信息输入界面开发计划

## 一、需求分析

根据用户要求，需要开发一个专业版的八字排盘信息输入界面，主要特点：

### 1.1 设计风格
- **现代极简主义 + 素雅国风元素**
- **专业性、严谨性、高精度**
- **无冗余信息**

### 1.2 配色方案
| 元素 | 颜色值 | 用途 |
|------|--------|------|
| 背景色 | #F9F7F3 | 浅米白背景 |
| 卡片色 | #FFFFFF | 纯白色卡片 |
| 阴影色 | #E0E0E0 | 浅灰阴影 |
| 主色调 | #1A1A1A | 墨黑文字 |
| 深青色 | #2A4A3F | 强调色、主按钮 |
| 暗金色 | #8B7D6B | 点缀色 |
| 边框色 | #E0E0E0 | 控件边框 |

### 1.3 功能模块（从上到下）
1. 标题区域：八字排盘 · 专业精准排盘
2. 性别选择：乾造（男）/坤造（女）
3. 历法切换：公历/农历（自动互转，处理闰月）
4. 出生日期：年/月/日滚轮选择器 + 节气提示
5. 出生时辰：十二时辰下拉 + 24小时制输入 + 早晚子时切换
6. 出生地选择：城市下拉 + 真太阳时校正显示
7. 高级设置（折叠面板）：真太阳时、起运岁数、闰月规则、人元司令
8. 底部按钮：精准排盘、重置、保存命例

## 五、核心算法说明

### 5.1 真太阳时计算
- 真太阳时 = 标准时间 + 时区修正 + 真太阳时差
- 真太阳时差计算公式：ΔT = 9.87sin(2B) - 7.53cos(B) - 1.5sin(B)
- 其中 B = 360° × (N - 81) / 365，N为积日

### 5.2 节气计算
- 使用太阳黄经计算二十四节气
- 立春：黄经315°，雨水：黄经330°，依此类推

### 5.3 早晚子时处理
- 早子时：23:00-24:00，属于当日
- 晚子时：00:00-01:00，属于次日

## 六、风险与应对

| 风险 | 应对措施 |
|------|----------|
| 历法计算精度 | 使用成熟的lunarcalendar库，验证关键日期 |
| 真太阳时计算复杂 | 参考天文算法标准，分步骤实现 |
| 城市数据庞大 | 使用常用城市列表，支持手动输入经度 |
| 界面复杂度高 | 采用折叠面板隐藏高级设置 |

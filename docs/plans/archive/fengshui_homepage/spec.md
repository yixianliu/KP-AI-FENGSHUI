# 风水八字排盘程序 - 信息录入首页 - 产品需求文档

## Overview
- **Summary**: 重新开发风水八字排盘程序的信息录入首页，采用简约国风极简设计风格，为用户提供专业、高效的出生信息录入界面
- **Purpose**: 优化用户体验，打造符合传统风水文化审美的信息录入入口，为后续八字排盘和AI命理分析提供高质量的数据基础
- **Target Users**: 需要进行八字排盘和命理分析的普通用户和专业爱好者

## Goals
- 打造简约国风极简设计风格的首页界面
- 提供直观、高效的出生信息录入体验
- 确保界面符合传统风水文化审美定位
- 实现桌面端窗口自适应缩放
- 实现清晰的信息录入流程和视觉引导

## Non-Goals (Out of Scope)
- 不修改现有的八字排盘计算逻辑
- 不修改AI命理分析功能
- 不添加额外的高级功能
- 不涉及移动端适配

## Background & Context
- 当前项目已有完整的八字排盘功能，包含输入面板和结果面板
- 现有界面采用较为传统的 PyQt5 风格
- 需要重新设计一个独立的首页界面，风格更加符合国风简约美学
- 项目使用 PyQt5 作为 GUI 框架，Python 3.x 作为开发语言
- 现有样式系统已初步设计好国风配色

## Functional Requirements
- **FR-1**: 提供独立的首页界面展示
- **FR-2**: 实现公历年份选择控件（支持合理年份范围）
- **FR-3**: 实现月份选择控件（1-12月）
- **FR-4**: 实现日期选择控件（根据所选月份自动匹配天数）
- **FR-5**: 实现出生时辰下拉选择（12时辰完整）
- **FR-6**: 实现性别单选按钮（男/女，默认无选择状态）
- **FR-7**: 实现【开始排盘】主按钮
- **FR-8**: 点击开始排盘后展示结果页面
- **FR-9**: 支持窗口尺寸自适应缩放

## Non-Functional Requirements
- **NFR-1**: 界面采用简约国风极简设计风格
- **NFR-2**: 使用低饱和度古风浅色系配色方案
- **NFR-3**: 布局采用居中对称设计，留白合理
- **NFR-4**: 所有输入控件操作流畅，无明显延迟
- **NFR-5**: 代码结构清晰，便于后续维护和扩展

## Constraints
- **Technical**: 使用 Python + PyQt5 框架，需兼容现有代码结构
- **Business**: 保持与现有八字排盘功能的兼容性
- **Dependencies**: 依赖现有的 core 模块和 ui 组件体系

## Assumptions
- 用户对传统风水命理有基本认知
- 用户主要在桌面端使用程序
- 现有计算逻辑保持不变，仅重新设计首页界面

## Acceptance Criteria

### AC-1: 界面整体设计符合简约国风风格
- **Given**: 用户打开程序首页
- **When**: 查看页面整体视觉效果
- **Then**: 页面呈现简洁大方、素雅沉稳的风格，无多余花哨装饰，符合传统风水文化审美
- **Verification**: `human-judgment`

### AC-2: 布局采用居中对称设计
- **Given**: 用户在不同窗口尺寸下查看
- **When**: 调整窗口大小
- **Then**: 所有内容保持居中对齐，布局规整对称，留白合理
- **Verification**: `human-judgment`

### AC-3: 年份选择控件正常工作
- **Given**: 用户在首页界面
- **When**: 选择出生年份
- **Then**: 年份控件提供合理的年份范围选择，操作流畅
- **Verification**: `programmatic`

### AC-4: 月份和日期控件联动正常
- **Given**: 用户已选择年份
- **When**: 选择月份和日期
- **Then**: 日期选项根据所选月份自动调整天数（如2月的天数）
- **Verification**: `programmatic`

### AC-5: 时辰选择包含完整12时辰
- **Given**: 用户选择出生时辰
- **When**: 打开时辰下拉菜单
- **Then**: 菜单包含子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥完整时辰
- **Verification**: `programmatic`

### AC-6: 性别选择功能正常
- **Given**: 用户选择性别
- **When**: 点击男或女选项
- **Then**: 单选按钮状态反馈清晰，默认无选择状态
- **Verification**: `programmatic`

### AC-7: 开始排盘按钮视觉突出且功能正常
- **Given**: 用户完成信息录入
- **When**: 点击【开始排盘】按钮
- **Then**: 按钮样式简约大气、视觉突出，点击后成功跳转到结果页面
- **Verification**: `human-judgment`

### AC-8: 界面响应式自适应
- **Given**: 用户在不同分辨率下使用
- **When**: 窗口尺寸变化
- **Then**: 界面元素自适应调整，保持布局美观
- **Verification**: `human-judgment`

### AC-9: 控件样式统一符合规范
- **Given**: 查看所有输入控件
- **When**: 无特殊操作
- **Then**: 所有输入框、下拉选择框采用统一圆角简约样式，边框纤细柔和，配色符合要求
- **Verification**: `human-judgment`

# 八字排盘程序界面优化与导出功能计划

## 一、项目现状分析

### 1.1 当前界面结构
- **主窗口**: 1000x750，包含标题栏、输入面板、结果面板、状态栏
- **输入面板**: 左侧固定宽度320px，包含姓名、性别、历法、日期、时辰输入
- **结果面板**: 右侧自适应，显示四柱八字、五行分布、十神分析、命局格局
- **状态栏**: 底部，显示状态和进度条

### 1.2 当前存在的问题
1. **界面臃肿**: 多个小部件分散，缺乏功能整合
2. **操作路径不清晰**: 用户需要理解多个输入项的逻辑关系
3. **导出功能缺失**: 无法将结果导出保存
4. **响应速度可提升**: 进度条动画略显生硬

---

## 二、界面优化方案

### 2.1 布局优化
1. **顶部区域重设计**
   - 精简标题栏，去除冗余装饰
   - 添加快捷操作按钮（新建、导出、帮助）
   - 优化配色方案，采用更柔和的中式传统配色

2. **输入面板优化**
   - 采用卡片式布局，分组显示相关信息
   - 添加即时输入验证和提示
   - 提供快速日期选择预设（如今日）
   - 时辰选择改为下拉菜单，显示时辰名称（子时、丑时等）

3. **结果面板优化**
   - 采用标签页式设计，将四柱、五行、十神、格局分为不同标签
   - 添加数据统计摘要栏
   - 支持结果的折叠/展开
   - 添加复制功能按钮

4. **状态栏优化**
   - 精简显示，只保留必要状态信息
   - 移除独立进度条，改为内联加载动画

### 2.2 视觉优化
1. **配色方案**: 保持中式传统风格，优化对比度和可读性
2. **字体排版**: 统一字体层级，增加间距
3. **交互动效**: 添加平滑过渡效果，提升响应感

### 2.3 操作流程优化
1. **快速开始**: 添加"一键排盘"功能，自动使用当前日期时间
2. **历史记录**: 添加最近使用的数据缓存
3. **快捷键支持**: 添加常用操作的快捷键

## 三、导出功能方案

### 3.1 导出模块架构
```
ui/
├── components/
│   ├── input_panel.py
│   ├── result_panel.py
│   └── export_dialog.py    # 新增：导出选项对话框
├── export/
│   ├── __init__.py
│   ├── base_exporter.py    # 导出器基类
│   ├── csv_exporter.py      # CSV导出
│   ├── excel_exporter.py   # Excel导出
│   └── pdf_exporter.py      # PDF导出
└── main_window.py
```

### 3.2 导出格式支持

#### CSV导出
- 编码：UTF-8 with BOM（确保Excel打开正常）
- 分隔符：逗号
- 包含所有四柱、五行、十神数据

#### Excel导出
- 格式：.xlsx
- 包含格式化的工作表
- 分别导出各分析模块
- 支持图表展示五行分布

#### PDF导出
- 完整排盘报告格式
- 包含所有分析结果
- 添加页眉页脚
- 支持打印预览

### 3.3 导出选项
1. **基础选项**
   - 选择导出格式（CSV/Excel/PDF）
   - 选择导出内容（全量/部分）

2. **自定义选项**
   - 添加用户备注
   - 选择要包含的模块
   - 自定义文件命名

3. **数据完整性保证**
   - 导出前数据校验
   - 生成导出报告
   - 记录导出日志

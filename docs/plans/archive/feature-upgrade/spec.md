﻿﻿﻿﻿﻿﻿﻿# 八字专业细盘与梅花易数升级项目 - 产品需求文档

## Overview
- **Summary**: 本项目旨在对现有八字排盘系统进行全面升级，新增专业细盘功能和梅花易数推算模块，并集成AI智能分析能力，构建完整的命理分析平台。
- **Purpose**: 解决现有系统分析维度不够详尽、缺少专业术语解释和可视化展示的问题，同时扩展梅花易数功能，提升整体命理分析的专业性和用户体验。
- **Target Users**: 命理爱好者、专业命理师、传统文化研究者

## Goals
- 将现有八字排盘功能升级为专业细盘系统，包含完整的命理分析维度
- 新增梅花易数推算模块，支持起卦、解卦全流程
- 构建标准化知识库，实现AI智能分析与个性化建议生成
- 提供专业术语解释和图表可视化展示

## Non-Goals (Out of Scope)
- 不开发移动端APP，保持现有PC端应用架构
- 不涉及其他命理流派（如紫微斗数、奇门遁甲等）的开发
- 不提供在线算命服务，保持本地应用模式

## Background & Context
项目基于Python + PyQt5开发，现有核心模块包括：
- core/baazi.py - 八字四柱计算核心
- core/wuxing.py - 五行分析
- core/shishen.py - 十神分析
- core/mingli.py - 命理分析（藏干、纳音、神煞等）
- core/yunshi.py - 大运流年计算
- core/ai_analyzer.py - AI分析器（对接讯飞星火API）

## Functional Requirements
- **FR-1**: 专业细盘功能升级
  - 完整保留传统八字排盘核心要素（四柱、五行、十神、大运、流年）
  - 新增更详尽的命理分析维度（十二长生、神煞详解、干支作用关系）
  - 提供专业术语解释功能
  - 实现图表可视化展示（五行分布饼图、十神分布图、大运走势图）

- **FR-2**: 梅花易数推算模块
  - 支持时间起卦、数字起卦、方位起卦等多种起卦方式
  - 实现完整的卦象分析（本卦、互卦、变卦、错卦、综卦）
  - 提供爻辞解读功能
  - 实现吉凶判断和趋吉避凶建议

- **FR-3**: 数据整理与AI分析处理系统
  - 制定标准化的数据整理流程
  - 结构化处理专业细盘和梅花易数相关内容
  - 构建专用知识库（排盘规则、命理知识、卦象解释、案例数据）
  - 开发接口将整理后的数据喂给AI模型
  - 实现AI对命理信息的智能分析、解读与个性化建议生成

## Non-Functional Requirements
- **NFR-1**: 代码可维护性 - 遵循模块化设计，每个功能模块独立封装
- **NFR-2**: 系统稳定性 - 异常处理完善，API调用有降级方案
- **NFR-3**: 用户体验 - 界面响应迅速，图表渲染流畅
- **NFR-4**: 数据安全 - 敏感信息加密存储，API密钥安全管理

## Constraints
- **Technical**: Python 3.x + PyQt5，使用现有第三方库（pymysql、requests、lunarcalendar等）
- **Business**: 基于现有项目架构进行扩展，保持代码风格一致性
- **Dependencies**: 依赖讯飞星火API进行AI分析，需保证网络连接

## Assumptions
- 项目运行环境已配置MySQL数据库连接
- 用户具备基本的命理知识或愿意学习相关术语
- 网络环境支持访问讯飞星火API

## Acceptance Criteria

### AC-1: 专业细盘功能完整性
- **Given**: 用户输入完整的出生日期和时间
- **When**: 系统执行八字排盘计算
- **Then**: 返回包含四柱、五行、十神、十二长生、神煞、大运、流年的完整专业细盘
- **Verification**: programmatic
- **Notes**: 所有分析维度数据需准确，符合传统命理规则

### AC-2: 专业术语解释功能
- **Given**: 用户在专业细盘界面查看分析结果
- **When**: 用户点击某个专业术语（如"正官"、"天德贵人"）
- **Then**: 系统显示该术语的详细解释和命理含义
- **Verification**: human-judgment

### AC-3: 图表可视化展示
- **Given**: 用户完成八字排盘
- **When**: 用户切换到可视化展示页面
- **Then**: 系统显示五行分布饼图、十神分布图、大运走势图
- **Verification**: human-judgment
- **Notes**: 图表需清晰、美观、易于理解

### AC-4: 梅花易数起卦功能
- **Given**: 用户选择起卦方式并输入相关信息
- **When**: 用户执行起卦操作
- **Then**: 系统生成完整的卦象（本卦、互卦、变卦、错卦、综卦）
- **Verification**: programmatic
- **Notes**: 卦象计算需符合梅花易数传统规则

### AC-5: 卦象分析与爻辞解读
- **Given**: 用户完成起卦
- **When**: 用户查看卦象分析结果
- **Then**: 系统显示各卦的详细分析、爻辞内容及吉凶判断
- **Verification**: human-judgment

### AC-6: AI智能分析功能
- **Given**: 用户完成八字排盘或梅花易数起卦
- **When**: 用户触发AI分析
- **Then**: 系统调用AI模型进行智能分析，返回个性化建议
- **Verification**: programmatic
- **Notes**: AI分析需基于结构化的知识库数据

### AC-7: 知识库构建与数据整理
- **Given**: 系统启动运行
- **When**: 系统加载命理数据
- **Then**: 系统从知识库中读取排盘规则、命理知识、卦象解释等数据
- **Verification**: programmatic

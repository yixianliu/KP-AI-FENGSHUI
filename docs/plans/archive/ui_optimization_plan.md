# 用户界面优化计划

## 需求概述
针对八字排盘应用的用户界面进行优化调整，包括左侧输入面板的紧凑化布局和右侧结果面板的排版修复。

## 问题分析

### 左侧输入面板问题
1. 输入框尺寸偏大，布局不够紧凑
2. 选择按钮尺寸过大，与整体界面比例不协调
3. 时间选择组件的下拉按钮与提示内容可能存在重叠

### 右侧结果面板问题
1. 初始状态下没有默认显示内容，用户体验不佳
2. 点击排盘按钮后可能出现元素重叠、布局错位等问题
3. 表格和卡片布局在不同屏幕尺寸下可能不稳定

## 具体任务

### Task 1: 优化输入框尺寸和间距
- **Priority**: P0
- **Description**:
  - 减小输入框的最小高度（从36px调整为32px）
  - 减小输入框内边距
  - 调整表单控件之间的垂直间距（从18px调整为12px）
  - 确保整体布局更加紧凑

### Task 2: 缩小选择按钮尺寸
- **Priority**: P0
- **Description**:
  - 减小切换按钮的最小宽度（从100px调整为85px）
  - 减小按钮内边距和字体大小
  - 确保按钮尺寸与输入框比例协调

### Task 3: 修复时间选择组件重叠问题
- **Priority**: P0
- **Description**:
  - 调整时间输入框的最大宽度
  - 确保下拉按钮不会遮挡提示文本
  - 优化时间选择区域的布局

### Task 4: 设置结果面板初始显示状态
- **Priority**: P0
- **Description**:
  - 在未排盘时显示友好的提示内容
  - 展示示例数据或引导用户进行排盘
  - 确保初始状态下布局完整

### Task 5: 修复排盘结果排版错乱问题
- **Priority**: P0
- **Description**:
  - 检查并修复表格布局问题
  - 确保卡片尺寸自适应
  - 修复元素重叠和布局错位
  - 确保滚动条正常工作

### Task 6: 测试UI兼容性
- **Priority**: P1
- **Description**:
  - 在不同窗口尺寸下测试布局稳定性
  - 验证交互元素的可用性
  - 确保文本内容清晰可读

## 文件修改清单
- `ui/components/input_panel.py` - 优化输入面板布局
- `ui/components/result_panel.py` - 修复结果面板排版问题
- `ui/styles.py` - 调整样式参数

- [ ] 结果面板初始状态显示正常

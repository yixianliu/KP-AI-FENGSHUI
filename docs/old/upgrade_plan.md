## 1. 现状梳理与核心评估

### 1.1 技术架构
- GUI：PySide6 Qt6，CustomTkinter风格备选
- 核心层 `core/`：`bazi_calculator`, `wuxing`, `shishen`, `yunshi`, `mingli`, `geju_analyzer`, `hexagram_analyzer`, `liuren`, `meihua`, `lunar_converter`, `calendar_utils`
- 存储：本地 SQLite `data/fengshui.db`，37表 Schema，`core/sqlite_db` 统一入口
- AI 接口：`api/agnes_client.py`，配置 `config.ini [agnes]`
- 兼容垫片：`core/_baazi_compat.py` 不可删除
- 测试：`tests/test_all.py` 57项，覆盖八字基础、梅花、大六壬稳定部分

### 1.2 已具备能力
- 八字四柱排盘：立春分界、真太阳时修正、五虎遁/五鼠遁
- 三术数一体：八字、梅花易数、大六壬
- 本地化隐私：全流程离线，数据不上云
- 导出：PDF/Excel/CSV
- AI解读可选：结构化JSON缓存

### 1.3 存在短板
- 数据准确性：数据源分散、无统一校验流水线、节气/月将依赖近似计算
- 算法：大六壬三传九宗门实现简化、神煞缺失、月将未按太阳黄经中气、十二长生为桩
- 业务流程：综合建议落库/导出链路未闭环、梅花/六壬导出入口缺失
- AI 系统：无RAG知识库、无古籍溯源、解读不可验证、缺乏确定性计算与AI解读分离
- 玄空飞星：未实现三元九运、飞星叠加、二十四山替卦等
- 工程化：核心算法未纯函数化、单元测试覆盖率<85%、无性能基准

## 2. 主流竞品深度调研

### 2.1 文墨天机专业版
- 定位：紫微斗数专业排盘工具，兼顾八字
- 优势：
  - 支持飞星、三合、四化、四柱多派别排盘逻辑 [d:\PythonProject\KP-AI-FENGSHUI\docs\upgrade_plan.md]
  - 算法经多版本校验，与传统手排高度一致【多特软件站】 
  - 运势推演：大限、流年、流月、流日全维度叠加
  - 界面贴近专业命理师操作习惯，信息密度高
  - 免费核心功能，无订阅壁垒
- 可借鉴：多派别切换器、命盘校验基准库、流月小限快速切换

### 2.2 大师八字 / 借问八字
- 定位：八字+紫微一体移动排盘
- 优势：
  - 真太阳时校正排盘，流月流日精细标注【App Store评论】 
  - 四柱+大运+流年+十神+五行旺衰+神煞+纳音+藏干一站式展示
  - 八字紫微二合一，减少跨App切换
  - 内置古籍资料，新手易懂
- 可借鉴：真太阳时校正UI、命盘全要素一屏呈现、历史命例云同步

### 2.3 知行八字 & 时者玄空风水
- 知行八字优势：
  - 真太阳时排盘 + 六爻/梅花/奇门/紫微/罗盘一站式
  - AR实景罗盘、电子罗盘磁北/真北校正、卫星地图叠加
  - 小成图、三元玄空、三合派水法盘、九运切换
  - 节气交接提示、流月定位修复
- 时者玄空风水优势：
  - 玄空飞星数字化：三元九运自动定盘、兼向替卦支持
  - 无限画布户型叠加，PNG/JPG导入方向校准
  - 流年流月飞星动态时间轴滑块
  - AI对话辅助解读，积分制
- 可借鉴：AR/实景罗盘、户型图叠加、流年动态可视化、AI对话分层

**行业趋势总结**
1. 数据校准：真太阳时、节气秒级计算成为专业标配
2. 多术数融合：八字+紫微+风水一体，跨系统交叉验证
3. 可视化：九宫飞星、罗盘AR、户型叠加
4. AI解读：以确定性排盘为输入，AI仅负责通俗化解读并引古籍出处
5. 离线隐私：本地优先，导出自有

## 3. 风水数据准确性优化

### 3.1 数据源验证
- 权威数据源清单：
  - 万年历锚点：`lunar_converter` 增加 1900-2100 节气时刻基准表，来源《中国天文年历》
  - 干支常量：统一使用 `core/ganzhi_constants.py`，禁止硬编码
  - 神煞表：从《子平真诠》《滴天髓》《穷通宝鉴》整理静态表入库
  - 玄空参数：三元九运起止、二十四山纳音、替卦表

### 3.2 数据清洗与标准化
- 校验层 `core/data_validator_v2.py`：
  - 输入：出生时辰、经纬度、公历/农历标志
  - 规则：子时 23:00-01:00 古法分界、立春年柱切分、真太阳时计算
  - 输出：标准化四柱JSON Schema，Pydantic v2 校验
- 清洗流水：
  `原始输入 -> 格式校验 -> 节气校准 -> 真太阳时修正 -> 干支映射 -> 校验哈希`
- 标准化存储：SQLite + JSONB 字段统一命名字段映射表

### 3.3 数据更新机制
- 版本化知识库：`database/knowledge_version.db`
- 自动更新检查：离线包签名校验，增量更新
- 变更日志：`docs/data_changelog.md`
- 测试锚点：万年历关键日期 57 个测试用例锁定

**技术选型**：Pydantic v2、LunarDate、pyephem/skyfield 精确天文

## 4. 核心算法重构与效率提升

### 4.1 八字四柱系统重构
- 纯函数化：`core/bazi/pillar.py` 分年/月/日/时四模块
- 年柱：立春为界，精确到分钟
- 月柱：五虎遁年起月法，支持月建中气
- 日柱：甲子参考日 `1984-02-02` 推算
- 时柱：五鼠遁日起时，子时 23:00 起始
- 性能：NumPy 向量化批量排盘，10万条 < 2s

### 4.2 玄空飞星系统新增
- `core/fengshui/xuan_kong.py`：
  - 三元九运推算、二十四山判定
  - 山星向星运星入中飞布顺逆、替卦规则
  - 流年流月叠加、七星打劫、城门诀
- 可视化：Canvas 3x3 九宫格，每宫山星/向星/运星/五行色标，吉凶红黑标注，生克箭头

### 4.3 紫微斗数 & 六爻
- 紫微：十四主星、辅煞、四化排布、十二宫大限推演
- 六爻：铜钱法/大衍筮法、世应定位、六亲六神

### 4.4 效率提升
- 缓存：`ai_cache.py` 扩展为计算缓存 LRU
- 并行：`concurrent.futures` 批量大运流年计算
- 测试覆盖率目标：核心算法 >=85%，pytest + hypothesis 属性测试

## 6. AI 模型辅助分析系统构建与集成

### 6.1 RAG 知识库
- 来源：《沈氏玄空学》《地理辩证疏》《子平真诠》《滴天髓》等
- 切分：500-800字符块，保留上下文
- 向量化：bge-small-zh，ChromaDB 本地
- 检索：BM25 + 向量混合，top-K=5 重排
- 古籍原文优先，强制引用标注出处

### 6.2 解读规范
- 确定性计算 + AI 解读分离架构
- 三段式：格局总评 / 分项分析 / 建议与注意事项
- 强制标注古籍出处，分层标注 学理定论 vs 民俗说法
- 尾部免责：仅供文化研究参考，不构成决策依据

### 6.3 技术集成
- LangChain + 本地 ChromaDB
- 多模型支持：OpenAI / DeepSeek / Qwen
- 缓存复用：相同排盘 + 问题命中缓存

**阶段 4 18-22周：验证上线**

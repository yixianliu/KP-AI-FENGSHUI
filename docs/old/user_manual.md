## 二、八字排盘

### 适用场景
个人命理分析：格局判断、五行旺衰、十神定位、大运流年、综合建议。

### 操作步骤
1. 点击顶部「**八字排盘**」标签
2. 填写输入面板：
   - **姓名**（可选，用于历史记录）
   - **性别**（男/女，影响大运顺逆）
   - **出生年份**（公历，支持 1900-2100）
   - **出生月份**（公历 1-12）
   - **出生日期**（公历 1-31）
   - **出生时辰**（小时，24 小时制；⚠️ 子时为 23:00 起）
   - **出生城市**（自动匹配经度，用于真太阳时修正）
3. 点击「**排盘**」按钮
4. 结果面板展示四柱干支、五行分布、十神配置、大运流年、综合批注
5. 点击「**AI 解读**」调用 AI 生成详细分析（需配置 API 密钥）
6. 点击「**导出**」保存 PDF/Excel/CSV

### 关键规则说明
| 规则 | 说明 |
|------|------|
| 年柱分界 | 以**立春**为界，非正月初一 |
| 月柱推算 | 五虎遁：甲己年起丙寅，乙庚年起戊寅… |
| 日柱推算 | 儒略日算法，锚点 1900-01-01 = 甲戌 |
| 时柱推算 | 五鼠遁：甲己日起甲子，乙庚日起丙子… |
| 子时界定 | **23:00-24:59 = 夜子时（当日）**，00:00-00:59 = 早子时（次日） |
| 真太阳时 | 根据城市经度自动修正，偏差范围 ±30 分钟 |

## 三、梅花易数

### 适用场景
即时占问：事业决策、感情走向、失物寻找、出行吉凶等具体事务。

### 起卦方式

**方式一：时间起卦**（最常用）
- 输入当前年、月、日、时（默认取系统时间）
- 系统自动按年月日时数叠加起卦
- 适合「随手一问」场景

**方式二：数字起卦**
- 输入 1-3 个数字（如报数、心中所想）
- 上卦 = 数字1 mod 8，下卦 = 数字2 mod 8，动爻 = 总和 mod 6
- 适合特定数字感应场景

**方式三：字数起卦**
- 输入问题文字，按字数起卦
- 字数 mod 8 为上卦，余数 mod 8 为下卦

### 操作步骤
1. 点击顶部「**梅花易数**」标签
2. 选择起卦方式（时间/数字/字数）
3. 填写对应参数和问题描述
4. 点击「**起卦**」
5. 结果展示：本卦 / 互卦 / 变卦、体用关系、动爻解析、吉凶判断
6. 点击「**AI 解读**」获取详细卦象分析

### 核心概念
| 概念 | 含义 |
|------|------|
| 体卦 | 代表问卦者自身（下卦为主） |
| 用卦 | 代表所占之事（上卦为主） |
| 体生用 | 泄气，事多阻碍 |
| 用生体 | 进益，有外力相助 |
| 体克用 | 得财，可掌控 |
| 用克体 | 官鬼，压力不利 |
| 互卦 | 事情发展中间过程 |
| 变卦 | 最终结果趋势 |

## 四、大六壬

### 适用场景
复杂事务推演：人事纠纷、合作评估、远行吉凶、诉讼得失等需要详细过程分析的场景。

### 操作步骤
1. 点击顶部「**大六壬**」标签
2. 填写输入面板：
   - **占问日期**（公历）
   - **占问时辰**（子丑寅卯…或 24 小时制）
   - **占事**（文字描述，供 AI 参考）
3. 点击「**排盘**」
4. 结果展示：
   - **天地盘**：12 地支在九宫中的分布
   - **四课**：干上/干阴/支上/支阴，含天将
   - **三传**：初传（事始）、中传（事中）、末传（事终）
   - **天将**：贵人、螣蛇、朱雀等 12 神将
   - **神煞**：驿马、桃花、禄神等
5. 点击「**AI 解读**」获取课体分析

### 核心规则说明
| 概念 | 说明 |
|------|------|
| 月将 | 太阳过宫位置，按公历月份对应（正月亥将…十二月子将） |
| 天盘 | 月将加占时，顺时针旋转 12 宫 |
| 四课 | 日干两支各取天上所临，组成四层关系 |
| 三传 | 由九宗门法则推得：贼克→比用→涉害→昴星→别责→八专→伏吟→返吟 |
| 九宗门 | 七种起传法则 + 两种特殊局（伏吟/返吟） |
| 天将 | 12 神将：贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后 |

### 九宗门速查
| 门法 | 触发条件 |
|------|----------|
| 贼克法 | 四课中有克（ Day Stem 克支 / 支克干） |
| 比用法 | 无克但有比（同日干阴阳），取比者 |
| 涉害法 | 多克或多比，取涉害深者 |
| 昴星法 | 无克无比，四课皆同（昴星） |
| 别责法 | 四课不全（仅三课），取干合支冲 |
| 八专法 | 干支同气（阴阳一致），取日上神 |
| 伏吟法 | 天地盘相同（值符加临本位） |
| 返吟法 | 天地盘对冲 |

## 五、玄空飞星

### 适用场景
风水布局：住宅/办公楼坐向分析、九宫飞星排盘、零正神判断、吉凶方位识别。

### 操作步骤
1. 点击顶部「**玄空飞星**」标签
2. 填写输入面板：
   - **坐向**：格式如「子山午向」「坐子向午」「午」等
   - **建造年份**：建筑落成年份（用于推算当运）
   - **当前年份**：分析基准年（用于流年叠加）
3. 点击「**排盘**」
4. 结果展示：
   - **九宫格**：Canvas 绘制 3×3 网格，每宫含山星/向星/运星
   - **宫位详情**：五行属性、吉/凶标注、生克关系
   - **文字分析**：零正神判断、上山下水格局、流年月飞星叠加
5. 点击「**AI 解读**」获取风水建议

### 核心规则说明
| 概念 | 说明 |
|------|------|
| 三元九运 | 每运 20 年，当前为九运（2024-2043） |
| 洛书九宫 | 中宫 5 → 四维八干定方位 |
| 山星 | 主管人丁健康，以坐山入中飞布 |
| 向星 | 主管财运事业，以朝向入中飞布 |
| 运星 | 当运之星，定整体吉凶基调 |
| 零正神诀 | 正神（当运）宜见山，零神（退运）宜见水 |
| 替卦 | 甲壬丙庚寅申辛亥癸等特定山位需替卦（用邻山替代） |
| 流年飞星 | 每年九星重新飞布，叠加到原盘分析当年吉凶 |

## 六、AI 解读功能

### 工作原理
1. **确定性计算层**：排盘数据 100% 由本地算法生成，不依赖网络
2. **RAG 知识库**：内置五经（《子平真诠》《滴天髓》《穷通宝鉴》《三命通会》《渊海子平》）摘要，检索匹配后注入提示词
3. **AI 解读层**：调用「龙虎山大师兄」AI 模型，结合排盘数据 + 古籍参考生成解读
4. **三段式输出**：格局总评 → 分项分析 → 建议与注意事项

### 使用前提
- 进入「设置」配置 API 密钥（密钥仅存于本机，不落云端）
- 密钥采用混淆加密存储，打包产物中无明文
- 可选：切换模型参数（温度、超时）

### 安全说明
- 排盘数据全程本地处理，不上传
- AI 请求仅发送脱敏后的排盘摘要
- 密钥经 `enc:v1:` 前缀混淆，不在源码中硬编码

## 八、常见问题

**Q: 子时怎么算？**
A: 23:00-00:59 都算子时。23:00-23:59 为夜子时（当日日柱），00:00-00:59 为早子时（次日日柱）。软件自动区分。

**Q: 农历生日怎么办？**
A: 当前版本暂不支持农历直接输入，请先用万年历换算为公历日期。

**Q: 真太阳时修正准不准？**
A: 根据城市经度自动修正，误差在 ±30 分钟内。建议使用出生地精确经纬度。

**Q: AI 解读可靠吗？**
A: AI 解读基于本地排盘数据 + 五经知识检索，仅供参考和文化研究，不构成决策依据。

**Q: 为什么排盘结果和网上工具不一样？**
A: 本工具严格遵循古法：年柱以立春为界、子时从 23:00 起、真太阳时修正。部分在线工具使用公历元旦分年或北京时间，可能产生偏差。

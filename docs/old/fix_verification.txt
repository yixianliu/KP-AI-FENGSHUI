f'参考范围：{html.escape(str(pct_min)):.0f}% - {html.escape(str(pct_max)):.0f}%' if pct_max != pct_min else f'参考值：{html.escape(str(pct_min)):.0f}'

问题分析:

- 然后试图对这些字符串使用 :.0f 格式说明符
- 但 :.0f 只能用于数值类型（int, float），不能用于字符串
- 因此出现: ValueError: Unknown format code 'f' for object of type 'str'

修复后代码:
f'参考范围：{html.escape(f"{pct_min:.0f}")}% - {html.escape(f"{pct_max:.0f}")}%' if pct_max != pct_min else f'参考值：{html.escape(f"{pct_min:.0f}")}'

修复说明:
- 首先使用 f-string 格式化数值: f"{pct_min:.0f}" (这会产生如"85"这样的字符串)
- 然后对格式化后的字符串应用 html.escape() 进行HTML转义
- 这样既保证了数值格式正确，又保证了HTML安全

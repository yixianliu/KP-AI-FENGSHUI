# 百度贴吧推广文案

## 标题
【技术讨论】KP-AI-FENGSHUI：本地离线排盘 v5.0.6，八字/玄空/梅花/大六壬一体化，算法开源可验证

## 发帖内容

各位吧友好，这里分享一个正在做传统命理数字化研究的开源项目，定位是工程级参考实现，欢迎技术党和研究党一起交流。

**项目简述**
KP-AI-FENGSHUI v5.0.6，一套完全本地运行的中国传统术数排盘工具，集成八字、梅花易数、大六壬、玄空飞星四大体系。核心设计哲学是确定性优先、隐私主权、算法透明。

**为什么做这个**
受够了在线工具的黑盒和隐私风险。年柱分界用元旦、晚子时处理错误、真太阳时不修正，这些问题在市面工具里很常见。本项目尝试用可验证的方式复现古法：
- 年柱以立春时刻为界，采用儒略日二分查找算法算节气
- 真太阳时 = 均时差 + 经度修正
- 晚子时 23:00-23:59 归属当日
- 月柱五虎遁、日柱锚点 1949-10-01=甲子推算、时柱五鼠遁

代码里每一步都有古籍出处注释，《子平真诠》《滴天髓》《穷通宝鉴》《三命通会》《渊海子平》五经为主要依据。

**技术架构亮点**
Core 层纯函数、无网络依赖，Service 层事件总线编排，UI 层 PySide6 自定义 Tkinter 风格。Pydantic v2 强类型校验，SQLite 本地持久化。100+ 单元测试，覆盖历史锚点。
AI 解读是可选的双轨架构，排盘数据 100% 本地确定计算，AI 仅在用户触发时基于脱敏摘要调用。RAG 知识库用 ChromaDB + bge-small-zh + BM25 混合检索，五经语料按 500-800 字切分，检索 top-K=5 重排序，强制三段式输出并标注出处。

**能做什么**
- 八字：四柱、藏干、纳音、十神、神煞、大运流年，五行量化
- 玄空飞星：三元九运、二十四山、飞星入中、流年叠加、Canvas 九宫渲染
- 梅花易数：时间/数理/铜钱起卦，体用生克、动爻解析
- 大六壬：九宗门起课
导出 PDF/Excel/CSV，历史记录本地管理。

**讨论点征集**
1. 节气时刻计算在不同经度下的边界处理，你们怎么看？
2. 晚子时归属问题，有没有遇到实盘不一致的案例？
3. RAG 解读如何平衡古籍原文引用和可读性？
4. 有没有兴趣一起做算法交叉验证？

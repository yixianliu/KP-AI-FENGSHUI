==============================================================

标题建议：
- 传统命理遇上现代工程：一款"不上云"的本地化八字/梅花/六壬排盘工具
- 开源免费、数据不上云：我把三大术数体系做成了一个本地离线工具
- 从"信任工具"到"可验证工具"：这款排盘软件把算法透明化了

正文：
--------------------------------------------------

作为一个程序员，我也曾对传统命理持怀疑态度。但深入研究后发现，八字、梅花易数、大六壬背后是一套严密的天文历法与逻辑推演体系——问题不在"术"，而在"工具"。

市面上绝大多数在线排盘工具存在三个硬伤：
1. **算不准**：节气换月、立春分界、真太阳时经度修正、早晚子时边界、五虎遁/五鼠遁……任何一环偏差，全盘皆错
2. **黑盒不可验证**：只能盲目信任，无法核对计算过程
3. **隐私裸奔**：出生时辰、地点、性别上传云端，甚至被用于 AI 训练

于是我花了大半年时间，把这套体系完整落地为 **本地离线、算法透明、数据不上云** 的专业工具——**KP-AI-FENGSHUI**。

🎯 它解决了什么问题？
--------------------------------------------------
✅ **算不准** → 整套天文历法算法固化本地，立春分界、真太阳时修正、五虎遁/五鼠遁全自动精准计算
✅ **无法验证** → 核心数据源自本地数据库，计算逻辑开放可查，结果可追溯、可复现
✅ **隐私泄露** → 排盘全程本地完成，敏感数据从未离开本机，彻底杜绝隐私外泄
✅ **解读贵、黑盒** → AI 解读做成可选功能，自带密钥、以本地数据为准、结构化输出、不强制订阅
✅ **难保存、难展示** → 一键导出 PDF/Excel/CSV，专业细盘可存档、可打印、可给客户展示

💎 它带来了什么独特价值？
--------------------------------------------------
🔒 **真正本地、真正隐私**：数据不出本机，离线也能用，适合严肃用户
🔍 **算法透明、结果可信**：展示与计算严格一致，杜绝"算一套、画一套"
🀄 **三术数一体**：八字、梅花易数、大六壬同一界面，无需多软件切换
🤖 **AI 解读可控可定制**：本地排盘为唯一输入，JSON 结构化输出，可缓存复用
🎨 **国风专业、导出无忧**：中式美学界面 + 专业细盘 + 多格式导出
🧪 **工程级质量保障**：100+ 单元测试，锁定万年历锚点与核心算法逻辑

🛠 核心技术栈
--------------------------------------------------
- 语言：Python 3.10+
- GUI：PySide6（原生跨平台，国风样式深度定制）
- 算法层：纯函数式设计，核心计算与展示彻底解耦
- 天文历法：自研高精度节气/真太阳时/月将算法，非查表法
- AI 集成：LangChain + ChromaDB 本地向量库，支持 OpenAI/DeepSeek/Qwen 多模型
- 数据持久化：SQLite 本地数据库
- 测试：pytest，覆盖率 85%+

📦 如何使用
--------------------------------------------------
方式一（源码运行）：
```bash
pip install -r requirements.txt
python main.py
```

方式二（免安装）：
直接运行 `dist/` 目录下的 `风水排盘专业工具.exe`

⚠️ AI 解读为可选功能，需自行配置合法 API Key；不配置也可完整使用全部排盘与导出功能。

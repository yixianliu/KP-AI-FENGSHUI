项目简述
KP-AI-FENGSHUI v5.0.6，完全本地运行的中国传统术数排盘工具，集成八字、梅花易数、大六壬、玄空飞星四大体系。设计哲学：确定性优先、隐私主权、算法透明。

为什么做这个
受够了在线工具黑盒和隐私风险。年柱分界用元旦、晚子时处理错误、真太阳时不修正都是常见问题。本项目尝试用可验证方式复现古法：
• 年柱以立春时刻为界，采用儒略日二分查找算节气
• 真太阳时 = 均时差 + 经度修正
• 晚子时 23:00-23:59 归属当日
• 月柱五虎遁、日柱锚点1949-10-01=甲子、时柱五鼠遁
代码每步都有古籍出处注释，《子平真诠》《滴天髓》《穷通宝鉴》《三命通会》《渊海子平》。

技术架构亮点
Core 纯函数无网络依赖，Service 事件总线编排，UI PySide6。Pydantic v2 强类型，SQLite 本地持久化。100+ 单元测试。
AI 解读可选双轨架构，排盘数据100%本地确定计算，AI 仅在用户触发时基于脱敏摘要调用。RAG 知识库 ChromaDB + bge-small-zh + BM25 混合检索，五经语料 500-800 字切分，top-K=5 重排序，强制三段式输出并标注出处。

能做什么
• 八字：四柱、藏干、纳音、十神、神煞、大运流年
• 玄空飞星：三元九运、二十四山、飞星入中、流年叠加、Canvas 九宫渲染
• 梅花易数：时间/数理/铜钱起卦，体用生克、动爻解析
• 大六壬：九宗门起课
导出 PDF/Excel/CSV，历史记录本地管理。

二、项目背景与业务价值
================================================================================

【2.1 痛点分析】

中国传统命理学（八字、玄空飞星、六壬、梅花易数等）在数字化过程中
普遍存在三类问题：

  1) 在线工具不严谨
     年柱以公历元旦为界、时辰按北京时间计算，与古法《子平真诠》
     《滴天髓》规定不符

  2) 在线工具涉及隐私
     出生日期、性别、姓名等敏感信息需上传至第三方服务器

  3) 算法与解读混杂
     计算结果与 AI 生成文本边界模糊，用户难以识别"学理定论"与"模型生成"


【2.2 项目定位】

本项目以"确定性计算 + AI 解读"双轨分离为核心架构：

  - 计算层：所有排盘、推演、干支计算 100% 本地执行，不依赖网络，
            不上传数据
  - 解读层：AI 解读为可选增值模块，仅发送脱敏后的排盘摘要至 API
  - 知识库：内置五经（《子平真诠》《滴天髓》《穷通宝鉴》《三命通会》
            《渊海子平》）摘要检索


【2.3 商业价值】

  文化价值：将传统排盘算法代码化，为数字人文研究提供可验证样本
  技术价值：Python 桌面应用 + RAG 知识库的落地范式，可供同类文化项目参考
  用户价值：提供隐私安全的离线排盘工具，降低传统文化学习门槛
  可扩展性：模块化架构支持二次开发、SaaS 化改造、教学课件制作

  三段式输出结构：

    - BM25 + 向量双通道检索，按相关度重排序

【5.2 典型算法实现示例】

  示例 1：八字时柱计算（五鼠遁）

    # core/bazi/_baazi_compat.py 简化示例
    # 参考：《子平真诠》卷九·论起例

    def calculate_hour_pillar(day_stem: str, hour: int) -> str:
        """
        五鼠遁时法：根据日干与小时推算时柱天干

        规则（甲己日起甲子，乙庚日起丙子…）：
            甲己 → 甲子   乙庚 → 丙子   丙辛 → 戊子
            丁壬 → 庚子   戊癸 → 壬子

        Args:
            day_stem: 日柱天干（甲乙丙丁戊己庚辛壬癸）
            hour: 24 小时制小时数（子时 23:00 起）

        Returns:
            时柱天干（如 '甲'、'乙' 等）
        """
        hour_starting_table = {
            '甲': '甲', '己': '甲',
            '乙': '丙', '庚': '丙',
            '丙': '戊', '辛': '戊',
            '丁': '庚', '壬': '庚',
            '戊': '壬', '癸': '壬',
        }
        # 子时从 23:00 起，(hour + 1) % 24 // 2 得到 0-11 的地支序号
        zhi_index = (hour + 1) % 24 // 2
        gan_index = (hour + 1) % 24 % 12

        # 天干顺序：甲(0) 乙(1) 丙(2) 丁(3) 戊(4) 己(5)
        #          庚(6) 辛(7) 壬(8) 癸(9)
        gan_start_idx = ['甲乙丙丁戊己庚辛壬癸'].index(
            hour_starting_table[day_stem])
        hour_gan = ['甲乙丙丁戊己庚辛壬癸'][(gan_start_idx + gan_index) % 10]
        hour_zhi = ['子丑寅卯辰巳午未申酉戌亥'][zhi_index]
        return f"{hour_gan}{hour_zhi}"


  示例 2：玄空飞星排盘核心逻辑

    # core/fengshui/xuan_kong.py 简化示例
    # 参考：《沈氏玄空学》卷一

    def fly_star_forward(start_palace: int, star_num: int,
                         target_palace: int) -> int:
        """
        顺飞星：从起始宫按洛书九宫顺序数 star_num 步至目标宫

        洛书九宫顺序：1→8→3→4→9→2→7→6→5

        Args:
            start_palace: 起始宫位序号（1-9）
            star_num: 需要飞的星数
            target_palace: 目标宫位序号（1-9）

        Returns:
            目标宫位实际飞入的星数
        """
        luoshu_order = [1, 8, 3, 4, 9, 2, 7, 6, 5]
        start_idx = luoshu_order.index(start_palace)
        target_idx = luoshu_order.index(target_palace)
        step = (target_idx - start_idx) % 9
        # 星数 = (星数 - 1 + step) % 9 + 1  保持 1-9 循环
        return (star_num - 1 + step) % 9 + 1

关键依赖约束（迁移/重构时必须保留）

  • 存储层唯一入口：所有读写必须经 core.sqlite_db.get_connection() → database/schema_sqlite.sql 建库 → data/fengshui.db。行工厂为 dict（兼容 row.get()）。
  • AI 链路：main_window → analysis_pipeline → agnes_client → config.ini[agnes]；config.ini 缺失 [agnes] 时 AI 优雅降级。
  • 兼容垫片：core/_baazi_compat.py 被 bazi_calculator / lunar_converter / mingli / shishen 引用，不可删除。
  • Schema 生成：改表结构应改 base.sql 后重跑 convert_mysql_to_sqlite.py，勿手改 schema_sqlite.sql 与 fengshui.db。
  • 打包：仅用 build_release.spec + managed Python 3.13.12，否则缺 python313.dll / shiboken6 不匹配。

风水排盘专业工具（KP-AI-FENGSHUI）v5.0.3
==========================================

    传承中国传统命理学精髓的本地化专业排盘分析工具
    开源 · 免费 · 本地运行 · 数据不上云

----------------------------------------------------------------------
一、这个软件是做什么的
----------------------------------------------------------------------

风水排盘专业工具是一款运行在你自己电脑上的传统术数排盘软件，
集成了三大核心板块：

    · 八字排盘 —— 根据你的出生时间排出四柱八字、十神、五行旺衰、
                  格局与大运流年；
    · 梅花易数 —— 用时间、数字、方位、文字、笔画、铜钱六种方式起卦，
                  推演本卦、互卦、变卦与体用生克；
    · 大六壬   —— 以太阳黄经定月将，排四课三传、十二天将与神煞，
                  进行传统高级占法的推演。

软件还提供可选的 AI 智能解读（"龙虎山大师兄"）：它以本地排盘
结果为唯一依据，输出结构化的分析报告，帮你把晦涩的术语翻译成
通俗易懂的人生参考。

----------------------------------------------------------------------
二、它为你解决哪些实际问题
----------------------------------------------------------------------

1. 算不准的烦恼
   节气换月、立春划分年柱、真太阳时经度修正、早晚子时边界、
   五虎遁/五鼠遁……任何一个环节理解偏差，四柱就会全盘皆错。
   本软件把整套天文与历法算法固化在本地代码里，输入出生信息后
   一键得到准确排盘，你不必再担心"我算得对不对"。

2. 想验证却无从下手的烦恼
   传统上你只能"信任工具"，无法判断它算得对不对。本软件算法
   透明：核心数据全部来自本地数据库，计算逻辑开放可查，结果
   可追溯、可复现，你随时可以核对。

3. 隐私泄露的担忧
   多数在线排盘工具要求上传出生时辰、出生地点，这些信息还可能
   被用于 AI 训练。本软件排盘全程在你的设备上完成，出生时间、
   地点、性别等敏感数据从未离开本机，从根本上杜绝隐私外泄。

4. 想要专业解读却门槛高、价格贵的烦恼
   专业命理解读服务普遍订阅收费、且只能"黑盒"输出。本软件把
   AI 解读做成可选功能：你只需配置自己的密钥，解读就以你的本地
   排盘数据为准，输出可阅读、可保存的结构化报告，不强制收费、
   不绑定订阅。

5. 结果难保存、难展示的烦恼
   纸笔或网页工具的结果难以归档，也不便用于教学或咨询。本软件
   支持将排盘与解读一键导出为 PDF / Excel / CSV，方便你存档、
   打印或向客户展示专业细盘。

五、主要功能一览
----------------------------------------------------------------------

【八字排盘】
  公历/农历自动互转；真太阳时经度修正（精确到分钟）；
  四柱（年/月/日/时）+ 藏干 + 纳音 + 空亡 + 十神；
  五行能量量化（月令权重 + 藏干本气/中气/余气）；
  格局判定（专旺/从格/扶抑/中和）+ 特殊格局；
  大运排列 + 流年分析 + 十二长生。

【梅花易数】
  六种起卦：时间 / 数字 / 方位 / 文字 / 笔画 / 铜钱；
  本卦 + 互卦 + 变卦 + 错卦 + 综卦；
  体用生克判断、动爻分析。

【大六壬】
  太阳黄经天文算法定月将（非经验表）；
  天地盘 + 四课（干上神/干阴/支上神/支阴）；
  九宗门三传 + 十二天将 + 神煞系统（驿马/空亡/六合等）。

【AI 智能解读（可选）】
  可选接入"龙虎山大师兄"接口，以本地排盘数据为唯一输入，
  输出结构化分析报告；支持八字/梅花/六壬三类解读分支；
  本地结果缓存，避免重复请求。

【数据导出】
  PDF / Excel / CSV，便于教学存档、咨询归档与分享。

六、使用方式
----------------------------------------------------------------------

方式一：运行源码（需 Python 环境）
  pip install -r requirements.txt
  python main.py

方式二：使用已打包的 Windows 程序
  直接运行 dist/ 目录下生成的"风水排盘专业工具"可执行文件，
  无需安装 Python。

AI 解读为可选功能，需在设置中自行配置合法 API 密钥后方可使用；
不配置也能完成全部排盘与导出功能。
